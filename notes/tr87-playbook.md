# tr87 攻关记录(六关全通, 100.00 满分, 2026-08-09)

127 步 vs 人类基准 414 步,六关全部触 115% 单关封顶。全新环境整条重放终验通过。

tr87 与 ls20 是仅有的两个纯 `[1,2,3,4]` 动作空间的公开环境,但它不是移动游戏:
这是一个**翻译规则归纳**游戏,ARC 静态题的交互版。

## 一、游戏结构

画面三块:上方**字典**(若干对"源语言符号 ↔ 目标语言符号"的框对,由横杠连接),
中间**题面**(源语言符号串,只读),下方**答案区**(目标语言符号串,可编辑)。

- ACTION3/4:光标在可编辑框之间左右循环
- ACTION1/2:当前框的内容在 7 个候选符号里正/反循环(实测互为精确逆操作)
- **没有提交键,没有任何中间反馈:答案全对的瞬间自动过关**

六关是一条精心设计的课程:

| 关 | 结构 | 新增考点 |
| --- | --- | --- |
| L1 | A→7,单符号对单符号 | 基本查表(但字典不完备,见下) |
| L2 | 7→B,一个符号译成 1~3 个符号 | 变长翻译串 |
| L3 | B→?,src 串长 1~3、dst 串长 1~2 混合 | 多对多、压缩翻译 |
| L4 | 无横杠的 4×8 框阵字典 | 同一任务换布局 |
| L5 | **玩法反转**:例句给定,字典可编辑 | 从样本反推字典 |
| L6 | 两级复合 A→7²→B,12 个字典框可编辑 | 复合函数 + 修字典 |

语言链跨关延续(L1 的目标语言是 L2 的源语言),题面符号 = 字典符号的
旋转/镜像变换,答案 = 对应变换作用于字典另一列。

## 二、破法编年

### L1-L4:clone 树穷举,答案位数是唯一的复杂度

关键洞察:**"没有反馈"只对真实环境成立**。`clone` 出来的环境里试错是免费的
(不计入动作分母),而"填对即自动过关"这个判定本身,在克隆世界里就是密集反馈。

做法:DFS 克隆树逐位枚举(每位 7 候选),每个动作后查 `levels_completed`,
命中后在真机上只走**最短按键序列**(每位取正/反循环较短方向,拨完立即过关)。

| 关 | 穷举规模 | 耗时 | 真机步数 / 人类 |
| --- | --- | --- | --- |
| L1 | 7⁵(2.3K clones) | 9 秒 | 14 / 54 |
| L2 | 7⁷(94K clones) | 6.5 分钟 | 25 / 58 |
| L3 | 7⁷(134K clones,97% 处命中) | 9.5 分钟 | 21 / 40 |
| L4 | 7⁷(68K clones) | 5.6 分钟 | 21 / 45 |

约 240 clones/s + 1800 acts/s。位数每 +1 成本 ×7:8 位约 1 小时,9 位约 8 小时,
**10 位以上穷举死刑**——所以穷举的真正角色是给规则归纳喂 ground truth。

### L5:结构化求解,从 570 万剪到 41

L5 光标夹的是字典框(8 个全部可编辑),下方例句是完整的 ground truth。
盲穷举 7⁸=576 万不可行,汉明距离递增(假设"只错几框")k≤3 也全空——
**初始字典几乎是全打乱的,不是小修**。

有效解法:每对字典枚举 (k_src, k_dst) ∈ 49 种环组合,筛出"存在例句映射 m 和
变换,使 src 框内容匹配 m 的题面符号、dst 框内容匹配 m 的答案符号"的组合,
4 对做笛卡尔积逐个 clone 验证。**41 个候选,瞬间命中,14 步 / 人类 71。**

注意:src/dst 两侧的变换必须**独立枚举**——绑定同一变换会 0 候选(见第三节)。

### L6:两级复合,谓词求解三次失败的教训

结构:3 条 A→7²(一变二)+ 3 条 7→B 映射,12 框可编辑,题面 3 符号 +
答案 6 符号是给定样本。穷举空间 7¹² ≈ 138 亿,只能结构化。

谓词:枚举 D1 侧(A框×77框)生成中间 7 串候选 → 6 个 (中间符号→答案符号)
查询去重 → 指派给 3 条 7→B 映射 → 全通过才 clone 验证。三版才通:

1. **第一版 0 命中**:假设"输出变换 = 输入变换"。这个 U=T 规则在 L1 成立、
   L2 就有反例,复合场景下彻底不成立。改成独立变换。
2. **第二版仍 0 命中**:做覆盖诊断(每层单独查有没有匹配)——各层全部健康,
   还暴露出**答案是回文布局 [a,b,c,c,b,a]**:A 符号的两个输出不在紧邻位
   (2i, 2i+1),在对称位 (i, 5-i)。加进布局枚举。
3. **第三版仍 0 命中**:真凶是查询去重用了**精确像素键**——回文对称位的符号
   是同类不同朝向,像素永不相等,6 个查询永远去重不到 ≤3 条映射。
   改成**变换等价类(canonical form)做键**后:2352 候选,第一个就命中。

32 步 / 人类 146,state=WIN。

## 三、可迁移的心得(按分量排序)

1. **"无反馈"≠"无抓手",先查判定在哪一层**。tr87 的判定(全对即过关)在
   clone 世界里就是免费的反馈信号。评测计分只数真实动作,克隆里烧多少算力
   都不要钱——这是本方案对人类基准 3 倍优势的全部来源。

2. **穷举是归纳的仆人**。L1-L4 穷举的产出不是那几个解,是 ground truth:
   拿到真实答案才能逆向规则(切分结构、等价类、U=T 的适用范围),规则才解得动
   L5 的 7⁸ 和 L6 的 7¹²。小实例穷举 → 逆向规则 → 规则攻大实例,这个循环
   比"一步到位猜规则"稳得多。

3. **符号匹配必须在变换等价类层面,不能在像素层面**。对称符号会产生系统性
   歧义(r90 匹配 = r270 匹配),精确匹配会把同类不同朝向当成两个符号。
   canonical form(全变换取 min)做键,一处改动让 0 候选变 2352。

4. **谓词 0 命中时,先做分层覆盖诊断,再放宽假设**。每层单独验证
   "有没有任何匹配"(B框环 vs 答案、7框环 vs 77 符号……),能立刻定位
   断在哪一层——第二次失败里,诊断顺手暴露了回文布局,比盲目放宽快得多。

5. **布局是隐藏假设,要进枚举空间**。"翻译串按题面顺序紧邻连接"在 L2 就
   被打脸(段可以重排),L6 又变成对称回文。凡是"输出摆在哪"的先验,
   都该作为枚举维度而不是硬编码。

6. **每关重探基本交互,不沿用上一关**。光标在哪些框间循环、环长几、
   ACTION2 是不是逆操作——L5/L6 的可编辑对象从答案区变成字典区,
   沿用假设会全盘错位。每关三个小探针(光标遍历、环长、判定),半分钟的事。

7. **框对齐差一列,结论全错**。7框/B框的符号提取偏了 1 列时,所有变换匹配
   失效,差点得出"字典是假的"的结论。符号提取后先肉眼抽查一个。
