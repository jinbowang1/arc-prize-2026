# 世界模型文献增量侦察 (2026-08-21, 补 08-06 那轮之后的新货)

四篇新核, 全部读过原文摘要/结论, 按"对我们 v4/v5 有什么用"组织。

## 1. Rodionov 消融 (arXiv:2607.15439, 07-16) — 对 v4 最重要

四个嵌套 agent 消融"可执行世界模型/简化/replay验证"三组件, 结论:

- **replay 验证是四个设置里唯一全胜的组件**(代价是算力)。→ 我们的 `verify_wm` 押对了, 而且要执行得更硬。
- 🚨**反直觉: 不带验证的可执行世界模型比纯文本基线还差**(gpt-5.5 两个设置都输)。
  → "让模型写世界模型代码"本身不是加分项, **验证才是**。别造不验证的世界模型。
- **定期简化(refactor 到更简形式)在 4 个设置里赢 3 个**。→ 已加进系统提示第 3 步。
  与我们 tr87 等价类定案(像素级精确匹配=过拟合)同源。
- 模型强度仍是第一因子; gpt-5.6-sol + 验证 = 公开集 25/25 全通 RHAE~99%(公开集已饱和),
  私榜表现未测。→ 比赛真命题仍是"把这套装进断网 27B"。

## 2. Explore Before You Solve / AERA (arXiv:2605.25931) — 探索预算的数学

- 把"动作效率 vs 信息增益"形式化, RHAE 平方惩罚下存在最优探索-规划平衡点。
- 实操结论: **规划前留 50-200 步探索预算**; 超过帕累托前沿的探索是负收益。
  → 系统提示改成"预算的 20%-40% 做实验"。
- **0.5B 模型 + explore/verify/plan 三阶段结构 = 4/25**(无结构基线 0 分)
  → 结构能驮着弱模型走, 对我们 27B 是好消息。
- ⚠️他们说公开集多数游戏可被"非智能策略"解掉 → 公开集分数别过度解读。

## 3. OCM 对象中心环境建模 (arXiv:2607.02846) — v5 方向

- 知识库=两半: **对象定义(Python 类)+ 依赖对象模型的可复用过程**; 每局后反思更新,
  且每次更新都要**回归验证所有过程仍能跑**。
- "渐进披露": 先看函数签名再看源码, 省上下文。
- → 对我们: REPL 命名空间天然支持(定义的函数跨轮保留, 已写进提示);
  跨游戏的"技能库"(Voyager 式)是 v5 的事, 先不做。

## 4. WorldEvolver 自进化世界模型 (arXiv:2606.30639) — 轻量借鉴

- 情景记忆(真转移检索模拟) + 语义记忆(从"预测-实际"落差提炼规则) + **选择性前瞻
  (不可靠的预测过滤掉不喂给规划)**; 全部 test-time, 不动权重。
- → 借鉴点: verify_wm 的报告不只判对错, **错的那几条转移就是下一个该做的实验**
  (从落差提炼规则)。已符合我们用法, 无需改码。
