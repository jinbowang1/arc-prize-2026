## 🚨 A/B 口径的一个坑（09-07 winframe 第一波暴露）

winframe 只在**过第一关的瞬间**触发。所以一局如果 0 关，它跑的其实就是原版代码——
这局的成绩差异纯属模型随机性，不能算到改动头上。

第一波看起来"实验组 3 关 vs 对照组 6 关"很吓人，拆开看差异主要来自实验组一局 ft09 打了 0 关
（该局 winframe 从未触发）；真正触发了的那局过 2 关，与对照组持平。

**通用规则：凡是「条件触发」的改动（winframe / expect / 跨关记忆），
A/B 必须只在触发了的子集上比，否则未触发局的噪声会淹没信号。**
分析脚本里对应的是「开张后额外过关数」这一项。

expect 明天也一样：模型不填 expect 的局等于对照，要按「填了 expect 的动作占比」分层看。

## 实验台需要加固（否则每一刀都判不了）

今天暴露的根本问题：**改动的效应量 ≈ 本地 A/B 的噪声 ≈ 隐藏集的方差**，三者同量级，谁也判不了谁。
- 隐藏集：同码方差 0.82（5.49 vs 4.67），而单刀预期收益也就 0.3~1
- 本地 A/B：12 局/组，开张才 7 局，触发子集更小

**加固方向（按性价比）：**
1. **加局数而不是加 passes**：公开集有 25 局，现在只跑 4 局。DeepSeek 快且 TPM 充裕，
   跑 12 局×2 passes×2 组 = 48 路、并发 8，约 1.5 小时，样本翻两倍。
2. **只挑会触发的局**：先用对照组跑一遍筛出「稳定开张」的局（今天数据：ft09/vc33 开张率高，
   ls20/cd82 基本不开张），A/B 只跑这些局，等于把样本效率翻倍。
3. **配对比较而不是均值比较**：同一局同一 pass 号在两组间配对，消掉局间差异。
   今天的分析脚本已按局分组，但还没做配对统计。

## 🚨 09-07 傍晚三个实验的结论（明天照这个改，别再走弯路）

| 机制 | 给的形式 | 模型是否用 |
|---|---|---|
| 赢帧进 state['history'] | 可选读的数据 | 0/61 |
| expect 字段 | 动作对象的可选字段 | 两轮 0 次 |
| replay() 函数 | 沙箱里的可选工具 | 0/28 |
| ACTION7 → UNDO | **动作**，进 valid_actions | **一轮就用** |

**结论：可选的东西模型一概不用。** 明天做世界模型，别再提供"工具"，要做成：
1. **每轮 user prompt 必现的一行**：「world model replay: 命中 x/y，首个失配在第 k 步（动作 A）」
   —— 没建立时显示「world model: none」，让缺失本身也可见
2. 命中率 100% 才允许用它规划（硬门，见五刀计划）
3. 世界模型代码要跨轮持久：沙箱每次从零起，需 tool_agent 侧保存 + 从 _serialized_runtime_state 回灌

配套已就绪：`replay()` 已在沙箱实现并编译通过（build_v14_expect），差的只是
「把命中率做成必现指标」+「代码持久化」这两件。

## 从 25 局轨迹挖到的、我们完全没有的三样东西（09-07 傍晚）

### 1. ACTION7 = undo ✅ 已修复并验证
4/25 局有。纯引擎实证四局全部成立。我们动作表原本缺它。模型拿到后一轮就主动用了。

### 2. 探索覆盖账本 ❌ 完全没有
`visited / coverage / unexplored / frontier` 在我们 prompts.py 和 tool_agent.py 里 **0 命中**。
Retrodict 有三类盘点，都是卡关时的 escalation 内容：
- 未访问的可达状态：「visited only 42/186 statically reachable logical cells」
- 日志无法解释的现象：「Log-unexplained inventory」
- 已排除的假设：「Falsified: ... Do not revisit them」

**跟我们的老诊断对得上**：57.8% 零动作轮 = 模型在原地空想，没有"还有什么没试"的账本。

**按 affordance 原则要做成每轮必现的指标**（纯算法可算，不需要世界模型）：
- 每个动作被试过几次、哪些动作从未在当前关试过
- 棋盘上哪些区域从开局到现在从未变化过
- 最近 N 步里有多少步没有改变 settled 盘面
