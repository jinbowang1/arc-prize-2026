# 09-08 两条结论：判据废了，以及"可选就是不存在"第四次成立

## 一、本地 A/B 用均分判据是废的

同一份代码、同一批公开集 25 局、单一配置未变，基线跑了三次：

| 次 | 均分 | 拿到分的局 | 说明 |
|---|---|---|---|
| 昨晚 (gate25 g0) | 1.81 | 9/24 | 闸门关 |
| 今天 (workbench g0) | 0.88 | 6/24 | 同配置, 提示词里多宣传了一个用不了的 numpy |
| 今天 (clean_g0) | 0.65 | 6/24 | 同配置, bug 修好后 |

**极差 1.16 分，标准差 0.61。** 单局分数标准差 3.29 而均值 1.11，变异系数 1.8 —— 方差比信号大。

自助法 95% 区间（24 局）：昨晚 [0.68, 3.27] / 今天 [0.16, 1.93] / 工作台 [0.51, 1.89]，**三者完全重叠**。

要检出多大的差异需要多少局（每组）：

| 效应 | 需要局数 |
|---|---|
| 0.25 分 | 793 |
| 0.50 分 | 198 |
| 1.00 分 | 49 |

现在是 24 局。**结论：除非一刀能带来 1 分以上，本地 A/B 用均分永远判不出来。**

顺带澄清两个旧困惑：
- 闸门那次 1.81 → 0.59 看着吓人，其中相当部分是方差
- winframe 在隐藏集掉 1.26 分，同样落在这个量级里；它被判负靠的是公开集 9.11 → 6.01 与隐藏集同向，不是单看隐藏集

### 判据应该换成什么

**过关局数 + 同局配对。** 伯努利变量，方差小得多；而且更贴近隐藏集的得分机制（分数几乎全靠第一关碰过）。同样的效应量，用过关局数需要约 60 局，用均分需要 198 局。配上 McNemar/符号检验，24 局已接近可用。

## 二、"可选就是不存在"第四次成立

| 给模型的东西 | 形式 | 实际使用 |
|---|---|---|
| `expect` 字段 | 可选 | 0 次 |
| `replay()` 工具 | 可选 | 0 次 |
| `world_model` + 命中率每轮可见 | 可选 | 0 次 |
| **持久工作台 + notes（09-08）** | **可选** | **notes 0/24 局，跨轮复用函数 2/24 局，numpy 占调用 2.1%** |
| `world_model` + 动作闸门 | **强制** | 1/10 → 16/16 |

09-08 实测细节：g1 组 24 局 2132 次 python 调用，模型定义了 154 个函数（顶层 90 / 缩进 64），但 **19/24 局从头到尾没定义过一个可复用函数**；tr87 定义 109 个却只复用 1 次。提示词 24/24 局都写着 "your workbench persists"。

**所以那场工作台 A/B 测的不是工作台**，是"模型在有工作台但不用时的表现"。难怪落在噪声里。

### 由此得到的下一刀

工具应当由我们提供，而不是指望模型自己攒 —— 全通方 Retrodict 也不需要模型攒工具，它有作者写好的 `arclog.py`，上来就 `steps = arclog.load()`。

已实现 `board_helpers`：grid() / at() / find() / counts() / diff() / moved() / crop() / objects()，注入沙箱 runtime 并写进提示词的"运行时变量"清单（模型为了用 current_frame 必读那一段）。开关 `ARC3_HELPERS`。A/B 进行中。

**验收顺序必须是：先查使用率，再看效果。** 使用率为零，效果数字不必解读 —— 这是工作台那场交的学费。

## 三、附带修掉的三个坑

1. **Clash 代理吞请求**：`unset http_proxy` 不够，Python 客户端会读 macOS 系统代理（Clash 12639），照样走代理并挂死 40 分钟。必须 `export no_proxy='*' NO_PROXY='*'`。已写进所有 run.sh。
2. **提示词与运行时不一致**：给工作台加开关时漏了 import 清单那行，关闭组被告知可用 numpy 而运行时挡着，白烧步数。已加测试锁死：遍历开关两态，比对"提示词是否宣传"与"运行时是否可用"，两者必须相等。
3. **macOS 没有 stdbuf**：`stdbuf -oL` 让整场实验静默秒退。改为全量日志写盘再提摘要。

## 四、与全通方的真实差距（干净对照）

只看 Retrodict 一次跑完且通关的 11 局：

| | Retrodict (gpt-5.6-sol, effort=max) | 我们 (DeepSeek V4 Flash) |
|---|---|---|
| 每动作输出 token | 928 | 1059 |
| 每动作耗时 | 22.5 s | 34.5 s |
| 每局动作 | 161 | 49 |
| 每局时长 | 60 min | 28 min |
| 每局成本 | $13.6 | 极低 |
| 结果 | 25/25 全通 | 9/24 局拿到分 |

**思考量与耗时是同一量级**，差距在每步的质量：ft09 它 4 步过第一关，我们 63 步没过；sp80 它 5 步，我们 120 步没过。它用 numpy 把棋盘读成数组、把规则解成方程、一次算出 13 个精确点击点；我们的模型在做试探性分析。

另外 26 局里 14 局是**续跑**（带着上次的 workspace 和 playbook 接着打），11 局用了外部视觉模型预读开局图 —— 条件并不完全可比，但 fresh 局的对照仍然成立。

环境是官方线上：26/26 局带 `containment.json` 自证（`arcengine` / `arc_agi` 均 import 不到），官方记分卡 card_id 与我们跑的是同一批环境 id。
