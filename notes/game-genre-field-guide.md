# 游戏种类野外手册 (2026-08-23 初稿, 待用户过目后接进 agent)

来源: 用户 08-22 定的方向——"人类基本上知道这是一个游戏、一个不是那么难的游戏,
玩过很多游戏就能推断出大概是啥游戏……实在不行就明示给模型"。
素材: 六局手工满分攻关(ls20/tr87/ft09/cd82/sc25/sb26) + 两局盲测(r11l/lp85)
的一手记录。**每条都有实战出处, 没有编造的种类。**

用法设计: 第二部分"上场版"整段嵌入模型第一次开口的提示词; 模型第一件事是
对号入座(报"最像哪一类+证据"), 然后按该类的打法走。种类判断错了没关系——
它只是先验, 真实转移会纠正它。

## 第一部分 完整版(给人看、给维护)

### 第 0 层: 对所有游戏都成立的常识(六局逐条验证过)

1. **目标几乎总在画面上明示**。区分两种区域: 动作改得动的=你的"答案区";
   动作改不动却有内容的=题面/目标显示器。过关条件在四个游戏上都是
   "把答案区弄成题面显示的样子"(cd82 答案区=题面 / ft09 填色=蓝图 /
   tr87 答案=词典映射 / ls20 钥匙形状=锁显示)。
2. **第一关是教学关**, 人类基准通常 20 步上下, 常常一两个显眼操作就过。
   最显眼的物体、唯一的异色块、正中的图案, 先试它。
3. **有些格子每步自己变**(步数条/计时器/预算条), 与你按了什么无关。
   识别法: 无论按什么它都在变。别把它当机制, 也别当血条恐慌。
4. **效果可能滞后一拍**(动作先进缓冲, 下个动作才结算), 过关信号也可能滞后。
   "按了没反应"先怀疑滞后, 再按一下看。
5. **动作有隐藏预算**(实测 128 击 GAME_OVER 的案例), 乱试是要花钱的;
   GAME_OVER 后一般回本关起点, 记住肇事动作别再犯。
6. **点击的有效目标是物体**(连通块), 一屏 4096 个坐标其实只有一二十个真目标。
7. **判定常忽略朝向**: 图形匹配按"形状"算, 旋转/镜像多半是渲染噪声
   (tr87 定案), 但颜色通常是本体维度(ls20 L5 定案)。
8. **有些动作必须成对才有效**("选中+放置", sb26 定案): 单个动作全"无效"时,
   先试两两组合再下结论。

### 第 1 层: 种类清单(按出现频率排)

**A. 复制图案类**(实证: cd82 / ft09 / sb26; 三局=八分之三, 最常见)
- 长相: 画面有一块题面图案(改不动)和一块答案区(能改), 两块尺寸相同或成比例。
- 目标: 把答案区逐格弄成和题面一样。
- 打法: 先弄清"笔"是什么——可能是大笔(一下盖几十格)、小笔(点一下改一小块)、
  换色器(循环换当前颜色)、零件库(选零件+放位置)。然后从题面反推需要哪几笔。
- 坑: 后涂盖先涂(顺序有讲究); 有的笔是"切换"型(再点一下变回去);
  提交型游戏要找"确认"键。

**B. 导航开锁类**(实证: ls20)
- 长相: 有一个随方向键移动的"角色"; 地图上有锁/门/出口; 角落常有面板
  显示角色当前状态, 锁上显示要求状态。
- 目标: 把角色调整成锁要求的样子(形状/颜色), 然后走进锁/出口。
- 打法: 先认出角色(按方向键看谁动了); 找到"变形/变色"机关格(走上去状态变);
  配好状态后**绕开**会破坏状态的机关格走到锁。
- 坑: 有能量条(每步扣, 耗尽回起点), 补给点一次性; 目标是"形状与颜色同时匹配"。

**C. 推箱子类**(实证: sc25 第 3 关形态)
- 长相: 可动块+同色插槽/凹槽, 方向键让块整体挪一格距。
- 目标: 把块推进对应插槽。
- 打法: 经典推箱子——注意块只能推不能拉, 别把块推进死角。

**D. 点灯开关类**(实证: ft09 第 6 关)
- 长相: 一片格子, 点一格会连带翻转它自己和邻近格(或同行同列)。
- 目标: 全亮/全灭/凑成目标图案。
- 打法: 先点两三下摸清"点一格翻哪些格"的模式; 翻转类游戏点击顺序无关紧要,
  每格只有点/不点两种(点两下=白花), 想清楚该点哪个集合再动手。

**E. 词典翻译类**(实证: tr87)
- 长相: 画面上有成对的"样例"(左边一个图案右边一个图案), 加一块待填区。
- 目标: 从样例归纳映射规则, 按规则填待填区。
- 打法: 某个键循环切换候选, 另一个键切换位置; 全对自动过关(没有提交键)。
- 坑: 匹配按形状等价类, 朝向不算数。

**F. 画符施法类**(实证: sc25 全貌)
- 长相: 一小块可画画布(如 3×3)+旁边小方框提示图案+一个角色+出口。
- 目标: 在画布上画出提示图案来释放技能(喷火/变身/传送), 用技能清障,
  最后**角色走进出口**——画布本身与过关无关。
- 坑: 最容易误判成复制图案类; 判据是"画对了图案画面却出现别的效果"。

**G. 连锁消除类**(实证: r11l 部分)
- 长相: 点某个关键位置引发大面积连锁变化(一下改上百格)。
- 目标: 用连锁把某个图形补完整/清掉。
- 打法: 优先点图形的中心、缺口、对称点这类"特殊位置"; 连锁大=方向对。

**Z. 都不像时**
- 回到第 0 层通用打法: 找答案区和题面 → 每个动作试一次记效果 →
  盯着"离题面差几格"这个数把它做小。

## 第二部分 上场版(嵌入首轮提示词, ~1400 字)

```
【背景知识】你在玩的是人类设计的小型解谜游戏: 一定能通关、不会太难、
第一关是教学关(常常一两个显眼操作就过)。老玩家的经验如下, 先对号入座
判断游戏种类, 再按该类打法行动; 种类只是猜测, 以实际反馈为准。

通用规律(前人实测):
- 目标几乎总在画面上明示: 动作改得动的区域是你的"答案区", 改不动却有
  内容的区域是"题面"。过关常常就是把答案区弄成题面的样子。
- 有些格子每步自己变(步数条/计时器), 与你的动作无关, 别当机制。
- 效果和过关信号都可能滞后一拍: "按了没反应"先再按一下看。
- 乱试有隐藏预算, 点击的有效目标是物体(连通块), 别扫坐标。
- 图形匹配一般不看朝向(旋转镜像不算), 但颜色算。
- 单个动作全都"无效"时, 试两两组合(可能要"选中+放置"成对用)。

常见种类与打法:
A 复制图案: 题面+答案区并排 → 弄清"笔"是什么(大笔/小笔/换色/选零件+放置),
  从题面反推笔画; 注意后涂盖先涂。
B 导航开锁: 方向键控制一个角色, 锁上显示要求 → 踩机关把自己变成要求的
  形状颜色, 绕开会破坏状态的格子, 走进锁; 注意能量条。
C 推箱子: 可动块+插槽 → 只能推不能拉, 别推进死角。
D 点灯开关: 点一格翻一片 → 先摸清翻转模式, 想好该点的集合再动手,
  同一格点两下等于白花。
E 词典翻译: 成对样例+待填区 → 从样例归纳映射, 循环键换候选填进去,
  全对自动过关; 匹配不看朝向。
F 画符施法: 小画布+图案提示+角色+出口 → 画对图案是放技能, 过关要
  角色走进出口, 画布本身不是目标。
G 连锁消除: 点关键位置引发大连锁 → 优先点中心/缺口/对称点。
都不像: 找答案区和题面, 每个动作试一次记效果, 把"与题面的差距"做小。
```
