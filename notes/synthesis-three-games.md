# 三游戏综合:从 ls20 / tr87 / ft09 到自动化 harness 的形状(2026-08-10)

三个公开环境全部满分(每关 115% 封顶,均经全新环境整条重放终验):

| | ls20 | tr87 | ft09 |
| --- | --- | --- | --- |
| 类型 | 移动/资源/导航 | 翻译规则归纳 | 蓝图填色/开关 |
| 动作空间 | 方向键 ×4 | 方向键 ×4 | 纯 click |
| 我方/人类 | 335 / 776 | 127 / 414 | 86 / 208 |
| 攻关耗时 | 约两天 | 一天 | 一天 |

这份笔记不复述各 playbook,只提炼**三局都成立的结构**,以及它对
"断网小模型自动通关"(比赛真命题)意味着什么。

## 一、三局通用的攻关循环

每个游戏表面毫无共通(感知层三次从零重写),但攻关过程收敛到同一个循环:

```
探测交互 → 对象化感知 → 假设规则 → 廉价验证 → (失败)诊断分层 → (穷途)兜底穷举 → 拿 ground truth → 逆向真规则
```

1. **探测交互**(每关重做,不沿用):每个动作改什么、可编辑对象是谁、
   状态环多长、判定何时触发、有没有动作预算。半分钟的小探针,
   跳过它的每一次都付出了成倍代价。
2. **对象化感知**:把 64×64 像素压成"少数语义对象"。ls20 是
   `(格, 形状, 颜色, 能量)`,tr87 是符号的形状等价类,ft09 是连通块。
   **三局的搜索空间都不在像素层,而在对象层**——对象化做错(朝向当特征、
   杂色块漏检),后面全错。
3. **clone 是整个方法的地基**:试错免费、不计分母,"填对即过关"的判定在
   克隆世界里就是密集反馈。三局对人类基准的全部优势都来自这一条。
4. **穷举是归纳的仆人**:小实例穷举的产出不是解,是 ground truth;
   拿到真实答案才能逆向规则,规则再攻穷举撑不住的大实例。
   tr87 的 L1-L4 穷举喂出等价类,ft09 的 L1-L2 穷举喂出蓝图语义。

## 二、两条被自己推翻的边界(方法论上最值钱的部分)

本仓库先后立过两条"方法失效边界",都被后续实验推翻:

| 原判断 | 推翻方式 | 修正后表述 |
| --- | --- | --- |
| tr87 全或无、无反馈,"搜索不是慢,是没有方向" | clone 试错免费 + 克隆树穷举满分 | 无反馈只对真实环境成立;判定本身在克隆世界里就是反馈 |
| click 类每步 4096 坐标,"穷举直接不成立" | ft09 连通块对象化后满分 | 有效分支 = 语义对象数;对象化感知是 click 的入场费 |

教训不是"边界不存在",而是:**边界声明必须绑定它的隐含假设**。
两条边界都在"感知停留在像素层/动作停留在坐标层"的假设下成立,
假设一换层,边界就塌。第三条(所有规则仍由人工归纳)目前仍然成立。

## 三、人机对照:tr87 的 U=T 事故

用户亲手通关 tr87 后一句"和方向没有任何关系",推翻了程序侧归纳了六关的
U=T 变换传递理论:判定定义在形状等价类上,朝向自始至终是渲染噪声。
按此重写后,L1-L4 的穷举(9 秒~9.5 分钟)全部退化为 0.1 秒查表。

三条定案:

1. 像素级精确匹配会把渲染噪声当规则本体(为此付出 30 万次克隆);
2. **归纳偏置的差异比算力差异更决定谁走得快**——人类第一关就砍掉朝向维度,
   程序到第六关才被数据逼着砍;
3. 人类先验(旋转不变性、对象恒常性)应作为先验硬编码进 harness,
   不能指望断网小模型自己归纳出来。

## 四、判定的分类学(三局实测)

过关判定是这类游戏唯一的外生反馈,它的"位置"决定攻关策略:

| 判定形态 | 出现处 | 对策 |
| --- | --- | --- |
| 静态谓词,每动作后检查 | tr87 全部、ft09 L1-L5 | 枚举目标态,clone 验证 |
| 静态谓词 + 资源约束 | ls20(能量/命数) | 规划器加资源下限约束 |
| **路径依赖**(同终态不同路径结果不同) | ft09 L6 | 枚举态失败时改枚举路径;格雷码每步一击扫态空间 |

另有两类隐藏机制会让实验结论整体作废,必须开局探明:
**动作预算**(ft09 第 128 击 GAME_OVER;速率好得不像话先怀疑游戏已死)和
**动画帧/决策帧混淆**(通关动画、闪烁拒绝都会污染 diff)。

## 五、自动化 harness 的设计蓝图(给比赛的)

把三局的人工流程翻译成程序分层——每层标注"已有实现"还是"真命题":

1. **交互探测层**(可完全自动化,已有雏形):动作 diff 分类、状态环测长、
   可编辑对象发现、动作预算探测。三局的探针代码已经高度模板化。
2. **对象化感知层**(半自动):连通块 + 网格周期检测 + 形状等价类
   (canonical form)。**杂色块/格纹块检测是已知缺口**。
3. **假设引擎**(真命题所在):谓词族枚举——查表/切分/蓝图/计数/对称/
   lights-out。三局全部命中这几族,但**族本身是人工提出的**;
   断网 LLM 的角色应是"提出谓词族",符号层负责枚举与验证。
4. **兜底穷举层**(可完全自动化):克隆树 DFS、汉明球、格雷码全态遍历。
   判定每步都查 + 单步验证便宜时,兜底的期望成本经常低于聪明假设。
5. **验证纪律**(不可妥协):搜索内通关 ≠ 解可复现;唯一判据是
   全新环境整条重放 + 官方 scorecard 对账。

一句话总结:**确定性的工作全部下沉到符号层(探测/枚举/验证),
LLM 只保留两件事——对象化的先验选择,和谓词族的提出。**
这与文献侦察的结论(Rodionov 消融:弱模型上确定性工作全下沉)完全一致,
现在有了三局满分的第一手实证。
