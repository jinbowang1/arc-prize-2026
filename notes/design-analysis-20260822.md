## 一、我们现在到底在哪: 三笔账

**第一笔: 本地"上帝模式"的账。** 六个游戏手工攻关满分、自动框架不用人帮忙能过
5/37 关。这些全靠克隆体——本地模拟器可以随意复制游戏状态免费试错。真赛场每个
动作都要通过网络发给主办方计分, 没有克隆体, 所以这笔账**直接换不成分数**。
它的价值在第三节讲。

**第二笔: 真赛场的账。** 第一次提交因为网关配置的分支写错, 一个动作都没发出去,
状态 ERROR。第二次提交(08-22 上午, 编号 55688015)正在跑, 用的是"27B 开源模型 +
让模型写 Python 代码来玩"的组合。按彩排推演, 这一发即使顺利跑完, 分数也接近 0:
每个游戏只摊到 4-6 次模型调用, 而模型头几次调用都花在"看清画面"上, 真正的
行动步寥寥无几。

**第三笔: 对手的账。** 榜首 3.57%。按计分规则倒推这个数什么水平: 一个 6 关的
游戏只过第 1 关, 得分是 1/21≈4.8%; 榜首 3.57% 大约相当于在四分之三的隐藏游戏里
过了第 1 关。里程碑一冠军 Duck 1.21%, 大约是四分之一的游戏过第 1 关。

**由此得出当前阶段比赛的真命题**: 给你一个没见过的游戏和大约 6 分钟, 尽量过掉
前一两关。拼的是广度和开局速度。我们本地最强的"深度攻关"能力, 在榜上暂时
用不上武之地——这正是"照抄别人方式闷头做"没有分数的结构性原因。

## 二、当前架构拿不到分的因果链

```
12 小时总墙钟 ÷ 约110个隐藏游戏 ≈ 6.5 分钟/游戏
→ 27B 模型每次调用要思考 60-90 秒 → 每个游戏只有 4-6 次调用
→ 彩排实测: Qwen3.8 花 2-3 次调用打印画面看图, 只剩 0-2 次在行动
→ 一关的人类基准就是几十步, 根本走不完 → 0 分
```

按层拆薄弱环节:

- **观察层**: 模型该看的东西(全图、有哪些物体、每个按键什么效果)没有一次性给够,
  逼它花宝贵的调用次数自己去取。[08-22 已改: 开局直接喂 64×64 全图; 但省调用的
  效果要用 Qwen 本尊在 GPU 上验证, DeepSeek 陪练复现不出这个习惯]
- **行动层**: 模型每次调用只产出几步动作。调用这么稀缺, 每次应该产出一段
  能自主连跑几十步的程序(带循环和判断的策略函数), 模型只在程序失灵时被叫回来。
- **世界模型层**: 几乎是空的, 见第三节。
- **记忆层**: 给模型的持久笔记本(notes)它没用起来; 游戏之间什么经验都不带。

## 三、"世界模型"在这个比赛里到底指什么

一句话: 本地的克隆体就是一个完美世界模型——想知道"点这里会怎样"就真点一下,
免费。真赛场把克隆体收走了, 每次"想知道"都要花计分动作。**世界模型的全部意义,
就是自己造一个克隆体的替代品, 把试错从计分的真机搬进不计分的脑内。**

拆成四个部件, 逐个对账(左列是两周克隆体时代练出的存货, 右列是真正上场的 agent
现在有什么):

| 部件 | 回答什么问题 | 本地框架里的存货 | 上场 agent 现有的 |
|---|---|---|---|
| 表征 | 画面里有什么 | 物体自动发现 / 步数条计时器自动剔除 / "答案区 vs 题面"区分 | 只有一个连通块函数 |
| 动力学 | 动作会改什么 | 动作效果覆盖表 / 谁受哪个动作控制 / 按键效果表 | verify_wm 验证器(模型很少主动用) |
| 目标 | 怎样算赢 | 因果目标识别(改得动的要变成改不动的那样), 四个游戏命中真实答案 | 没有, 靠模型现场猜 |
| 规划 | 怎么走最省 | 各种搜索器 | 没有, 靠模型手推 |

断层一目了然: **存货一件都没接进上场的 agent**。Duck 的做法是给模型一只裸手
(空的 Python 解释器); 我们照抄了裸手, 却把自己独有的一箱工具留在了仓库里。
把左列接进右列, 就是相对 Duck 方式的差异化, 也是对"还在照抄里程碑一"的回答。

### v4 设计草案(待用户拍板)

1. **开局零调用**: 感知层自动跑完(物体清单/计时器剔除/答案区候选/每个按键
   试一次的效果表), 连同全图一起作为第一次调用的输入——观察的钱由代码出。
2. **每次调用产出一段程序**: 模型写 solve()/policy() 这类能连续行动几十步的
   函数; 真实转移自动累积进历史记录。
3. **世界模型闭环**: 模型写 predict(状态,动作)→新状态 → verify_mm 在历史上逐格
   对账 → 不合格自动报差异格喂给下一轮修 → 合格的进笔记本跨关沿用。
   验证过的动力学模型是"脑内规划"的许可证(消融实证: 不验证的世界模型比没有还差)。
4. **目标自动候选**: 因果目标识别自动产出"过关条件候选"给模型验证, 免得从零猜。
5. **兜底**: 模型垮掉或提前收工时, 零模型的乱点探索器接管捡分(08-22 已实现)。

风险与对照要求: 每条接线单独做单变量对照; "换模型=换书写习惯"和"提示词一句话
反噬"都有前科, 上场前必须用 Qwen 本尊在 GPU 上彩排。
