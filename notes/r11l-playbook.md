## 一、机制 (源码 + 克隆体实测)
- 只有点击。棋盘上的 5×5 菱形是**站点**(`roefwulewcui-<组>`), 同组同色, 当前选中的那个显示为白色(`color_remap 3→0`), 初始选中离原点最近的。
- **点站点 = 选中它; 点别处 = 把选中的站点搬到那里**(一步到位, 不是"沿路走")。斜线只是从站点连到标记的装饰。
- 每组有一个 20 格实心菱形**标记**(`roefwu-<组>`), 位置 = **该组所有站点中心的重心**(整除), 站点一动它就重算。
- 每组有一个 12 点空心菱形**靶环**(`flkdtg-<组>`), 与标记同色。**过关 = 每组标记与自己的靶环有像素重叠**(容差约 ±2 格)。L1 靶心 (21,39), 终点站在 (59,27) 时另一站得在棋盘外 → 必须先点灰站把选中换过去、再搬。
- 色 a 的大块 = **危险**(`defgjl`): 搬完后若标记压在危险上 → 闪烁动画、记一次、站点弹回; 5 次判负。约束的是标记不是站点(站点可以搬进危险区)。色 2 = 墙(`wakneh`), 站点不能搬进去。
- 每关 **60 次动作上限**(第 0 列白条 = 剩余数, 过关回满); 后面关卡有 `puukul` 色块, 标记压过会吸走颜色, 过关还要求标记颜色集合 = 靶环颜色集合。
- 关卡递进: L1 一组两站; L2 两组(3 站 + 2 站)+ 危险带; L3 两组(4 站 + 2 站)+ 危险带翻倍, 4 站全得搬到右下角且重心得一次跳过危险带。

## 二、解法
- L1-L4(纯搬站): 终态 `Σ站点 = n×靶心`; 危险带横贯时单次搬动跳不过去, 要先把别的站搬到"让重心绕开危险带"的位置(L3 四站全搬到右下, 7 步)。
- L5-L6(吸色): 标记空白, 场上有多块 `puukul` 色块和干扰色块; 靶环颜色集合 = 名字里拼出来的两三种色。**整压第一块染满 → 侧压第二块(标记左半换色、右半保留) → 底压第三块(下半换色、上两行保留左右两色) → 进环。** 关键是"部分重叠"而不是"完全重叠", 两站组用中点、三站组用整除重心算落点; 中途重心别碰到别的色块(会吃错色)。L5 7+14=21 步, L6 12+18=30 步。
- 落点不能压在别的站点身上(点到站=选中); 站点本身可以压在色块/靶环上, 只有标记才吸色/进环。
终态约束 `Σ站点 = n × 靶心`(±容差); 枚举要搬的站点子集与落点, 最后一个由等式解出; 落点不能压在别的站点上(点到站=选中); 再排列搬动顺序, 保证每一步之后的重心都不在危险上。L1 3 步, L2 5+4=9 步。

## 三、手册在这一局哪里出错 (对着 10 份手册臂 transcript)
手册臂原话:
- "This looks like a 'navigate and unlock' game. The white box is the player, and I need to move it along the path to the target. But the only action is MOUSE, not arrow keys."
- "The diamond at rows 18-24 could be a template, and I need to recreate it somewhere." / "this might be a 'copy pattern' game"
词频(每千思考词): 手册臂 room 9.0 / template 2.74 / navigate 0.26; 原版臂 room 0 / template 0.03 / navigate 0.08; 只给一次臂 room 0.06。
**错在哪**: 手册的家族目录(B 导航"5×5 方块是你、走进房间"; A 复制图案"模板/答题区"; G "优先点中心")让模型先把 r11l 归类, 然后按那一类的动作模型行动——反复点菱形中心、点"路径"、等"角色走到出口"。而 r11l 的真机制"点空地 = 搬站点、重心进环"不在任何家族里, 原版臂靠"每种东西都点一遍"(含空地/紫点)撞出来了, 手册臂被叙事锁住从没点过空地。
**手册要改的**: ① 家族目录只写"识别特征", 删掉"怎么做"(尤其 B 的"走进房间"、G 的"优先点中心/缺口/对称点"); ② 加一条通用探测规则: "**点击类游戏先各点一次: 每种物体、物体中心、空地; 空地点击也可能移动选中物**"; ③ 明写"归类只是假设, 第一个假设被一次实验否定就换, 不要在同一假设下重复点同一目标"。
